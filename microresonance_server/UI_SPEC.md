# Спецификация UI MR Scope (Актуальная)

## Структура интерфейса
Графический интерфейс (GPU) разделен на функциональные вкладки, управление которыми осуществляется через верхнее меню. Правая панель управления (MANUAL/AUTO SCAN) доступна на большинстве экранов.

### 1. RAW (Осциллограммы)
- **Файл:** `internal/app/gui/screen_scan.go`
- **Описание:** Отображает сырые данные с датчиков ADXL (X, Y, Z) и ADS8681.
- **Инструменты:** Слайдеры временного окна (t), вертикального масштаба (Y) и размера БПФ (FFT).

### 2. BANDS (Частотные полосы)
- **Файл:** `internal/app/gui/screen_bands.go`
- **Описание:** Разложение сигнала на 8 частотных полос с помощью IIR-фильтров в реальном времени.
- **Особенности:** Клик на график любой полосы открывает всплывающее окно с увеличенным масштабом (zoom x3) и возможностью заморозки (Hold).

### 3. DISCOVERY (Первичный алфавит)
- **Файл:** `internal/app/gui/screen_discovery.go`
- **Описание:** Визуализация первичного алфавита (связка Exciter + Band).
- **Метрики:** Отображение сырой энергии (RawE) и относительной энергии (E_rel) по каждой ячейке адреса.

### 4. ALPHABET (Токены форм)
- **Файл:** `internal/app/gui/screen_alphabet_draw.go`
- **Описание:** Основной экран устойчивых токенов (глифов).
- **Режимы отображения:**
    - **Combined:** Усредненная форма волны.
    - **3 axes:** Раздельные графики по осям X, Y, Z или фазовые портреты (Lissajous).
- **Интерактивность:**
    - **Animation Popup:** Клик по карточке открывает окно с цикличной анимацией истории (до 256 кадров).
    - **Управление анимацией:** Кнопки Play/Pause, Close, слайдер глубины истории (1-256).
    - **Сравнение:** Сравнение двух токенов (Ctrl+клик), просмотр метаданных, фильтрация по количеству вхождений (x≥N).

### 5. TRAINER (Обучение)
- **Файл:** `internal/app/gui/screen_trainer.go`
- **Описание:** Интерфейс для записи датасетов и калибровки действий.
- **Протокол:** REST -> DO -> RELAX.

### 6. MEANING (Интерпретация)
- **Файл:** `internal/app/gui/screen_meaning.go`
- **Описание:** Вывод предсказаний обученной ML-модели в реальном времени.
- **Связь:** Взаимодействует с Python-скриптами через `internal/ml/worker`.

### 7. XCORR (Кросс-корреляция)
- **Файл:** `internal/app/gui/screen_xcorr.go`
- **Описание:** Анализ фазовых сдвигов и корреляции между различными сенсорами.

## Панель управления (Sidebar)

### MANUAL (Ручной режим)
- Настройка частоты (80–1200 Hz), интенсивности и фазы (0/180°) для левого и правого каналов.
- Режим **LINKED** для синхронного управления.
- Кнопка **PANIC** для мгновенной остановки стимуляции.

### AUTO SCAN (Автоматические пресеты)
- **FAST SCAN:** Экспресс-диагностика частотного отклика.
- **PHASE SCAN:** Проверка реакции на инверсию фазы.
- **DUAL ASYM:** Тестирование асимметрии каналов.

## Технические детали реализации
- **Движок:** Ebiten (v2)
- **Шрифты:** Стандартный debug-шрифт Ebiten для минимизации задержек.
- **Обновление:** Пайплайн обработки отделен от цикла отрисовки, что позволяет поддерживать стабильные 60 FPS при отрисовке, даже при тяжелых вычислениях в фоне.
