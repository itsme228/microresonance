# Слоистая архитектура: «картинка» как энкодер + якорь инвариантов

Идея: не «вместо цифр», а **слоисто** — как в USBridge: сырое → структурированное → смысл. Слои здесь нейросетевые.

---

## Когда «как картинка» лучше

1. **Сигнал сложнее инвариантов** — 3 вершины + ΔT/ΔA не хватает, теряется микротекстура → CNN по форме выигрывает.
2. **Обобщение на новые типы глифов** — модель, которая видит форму/спектр, легче находит новые классы.
3. **Действия внутри модели** — сначала «компоненты», потом «собрать глиф», потом «смысл».

## Когда «как картинка» хуже

1. **Переобучение на сетап** — картинка формы легко запоминает крепление, датчик, шумы. Инварианты — античит.
2. **Данных нужно больше** — raw/изображения требуют разнообразия.
3. **Сложнее отладка** — с инвариантами видно, что модель «думает».

---

## Компромисс: слои гибридно

### (A) Текущая архитектура `full`

- **Ветка 1 (главная):** features[17] → MLP → 32 (инварианты).
- **Ветка 2:** shape[64] → малый 1D-CNN (Conv 16@8, Pool 4, Conv 24@4, GlobalAvg) → 24.
- **Ветка 3:** x,y,z[64] каждый → лёгкий 1D-CNN (Conv 8@8, Pool 4, GlobalAvg) → 8×3 = 24.
- **Ветка 4 (опционально):** reaction[17] → MLP → 8.
- **Слияние:** concat(32, 24, 24[, 8]) → GRU(64) → head.

В GRU идёт уже сжатое представление (80–88 dim), не сырые 64×3.

### (B) Вариант `usbridge_style`

- **Слой 1 — сжатие формы:** shape + x,y,z как **4 канала** (64, 4) → один 1D-CNN (Conv 32@8, Pool 4, Conv 48@4, GlobalAvg) → **48** (learned encoder по «картинке» формы).
- **Слой 2 — якорь:** features[17] → MLP → **32** (инварианты как стабилизатор).
- **Слой 3 (опционально):** reaction → отдельная ветка (в текущей реализации пока не добавлена).
- **Слой 4 — динамика:** concat(form_emb, anchor_emb) → **80** → GRU(64) → head.

Отличие от (A): форма (shape + x,y,z) обрабатывается **одним** энкодером по 4 каналам, без разделения на отдельные ветки shape и xyz. Инварианты по-прежнему идут отдельным якорем.

---

## Практика: не 2D-картинка, если не нужно

Для вибраций чаще эффективнее:

- **1D CNN** по сигналу (быстрее и проще, чем изображение),
- или **спектр/мел-спектрограмма** — если важна частотно-временная структура,
- плюс multi-scale (несколько окон/stride).

Вариант `usbridge_style` использует 1D CNN по (64, 4) — один временной ряд с 4 каналами, без перехода в 2D.

---

## Сравнение (A) и (B)

| Аспект | full (A) | usbridge_style (B) |
|--------|----------|---------------------|
| Форма | shape отдельно (24) + x,y,z по отдельности (8+8+8) | Один энкодер по 4 каналам → 48 |
| Инварианты | Ветка 32 | Якорь 32 |
| GRU вход | 32+24+24 = 80 (без reaction) | 48+32 = 80 |
| Переносимость | Разные ветки под shape и xyz | Один энкодер — проще перенос между сессиями? |

Запуск экспериментов: `train_model.py --sequence --experiment` перебирает варианты, включая `usbridge_style` и `full`, и выводит val_acc/val_loss для сравнения.
