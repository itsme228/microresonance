# Контракт данных и UI: LOCKED vs CANDIDATES (частотная модель)

> **Новая архитектура:** токенизация по **форме** и **остаточной энтропии** описана в **[SHAPE_TOKEN_CONTRACT.md](./SHAPE_TOKEN_CONTRACT.md)**. Там же — контракт структур данных (ShapeVector, Token, Occurrence, ResidualStep), псевдокод, параметры по умолчанию и разделение ESP32/сервер. Ниже — контракт текущей частотной модели (legacy).

## 1. Спецификация поведения (10–20 пунктов)

1. **RAW** — рисует только сырые графики (буфер ADXL/ADS, FFT по текущему окну). Никаких кандидатов/токенов.
2. **CANDIDATES** — список живых кандидатов из CandidateStore; обновляется при каждом шаге детекции (~100 ms).
3. **LOCKED** — список только из PatternStore; отрисовка **только** по сохранённым данным паттернов (в т.ч. glyph_data).
4. **CandidateStore** — живое: обновляется при каждом вызове UpdateFromFFT (magX, magY, magZ, freqs, x, fs, n, окно W, стационарность A_cv, A_slope, …).
5. **PatternStore** — замороженное: токен добавляется/обновляется **только** по событию LOCK, когда **окно W стационарно** и hold ≥ T_lock (см. п. 8).
6. **glyph_data (GlyphData)** — при LOCK вычисляется из стационарного окна W. **При merge обновляется инерционно (EMA)**. История сохраняется в LastNGlyphX/Y/Z (до 256 кадров) для анимации и нейросети.
7. **Бесконечный TTL** — по умолчанию токены никогда не удаляются (`glyphTTLSec: 0`). Алфавит растет неограниченно.
8. **LastRawDetection** — одно значение для отладки: последний peak_freq/peak_amp/noise_floor/amp_norm (обновляется при каждом FFT).
9. **Стационарное окно (модель окна для глифа):**
   - Держим скользящее окно **W** (например 0.6 с). Кандидат существует, если есть пик f0 в 0.2–2 kHz и amp_norm > thr.
   - **LOCK разрешён только если окно стационарно:** (1) f0 держится в пределах ±Δf на протяжении накопленного hold; (2) огибающая env(t) вокруг f0 (I/Q демодуляция + LPF) стабильна: **cv = std(env)/mean(env) < A_cv**, **|slope(env)|/mean(env) < A_slope**. При несоблюдении стационарности hold не растёт / сбрасывается.
   - При первом LOCK **GlyphData** вычисляется из текущего стационарного окна W.
10. **Глиф = envelope glyph:** env(t) вокруг f0 (I/Q + LPF), downsample до 32 точек (16×min + 16×max по сегментам).
11. При **Merge** (совпадение с существующим токеном): обновляем **metadata** (Occurrences++, LastSeenTs, Amp/RatioXY/RatioXZ/Confidence EMA) и обновляем форму по EMA. История с таймингами сохраняется в кольцевой буфер LastNGlyphX/Y/Z (256 кадров).
12. **High Diversity Mode:**
    - Отключены **Probation** (принудительное слияние похожих новых глифов в старые).
    - Отключены **Fallback** (слияние при несовпадении топологической сигнатуры или частоты).
    - Отключено слияние между соседними полосами (Cross-band).
    - Слияние происходит **только** при строгом соответствии всех условий (Band, Signature, Frequency, Shape Distance).
13. **min_freq** (например 20 Гц): lock запрещён при f0 < min_freq (поза/качание → мусор).
12. **Δf_merge < Δf_lock**: merge строже lock; иначе всё сливается в один токен и «переобувается».
13. Отрисовка CANDIDATES: глиф кандидата может пересчитываться по текущему буферу (с кэшем 100 ms) — живые волны.
14. Отрисовка LOCKED: глиф рисуется **только** из Pattern.GlyphData; **не** читаем g.buf, **не** вызываем GetOscilloPointsForPattern.
15. FFT и детекция запускаются периодически (например каждые 100 ms); отрисовка UI ~40 FPS.
16. Цвета: кандидаты — красные→жёлтые по прогрессу hold; locked — зелёные.
17. LOCKED плитки: polyline по 32–64 точкам (glyph_data), без лагов; при желании alpha по last_seen.

## 2. Инварианты (что запрещено)

- **LOCKED-глиф НЕ должен пересчитываться каждый кадр** (или по таймеру 100 ms).
- **LOCKED не должен брать данные из g.buf напрямую** при отрисовке.
- **GlyphData обновляется** при merge (перезапись новым — эволюция) и при **явном** действии «Replace glyph» (ReplaceGlyphByID). История LastNGlyphTs для нейросети.

## 3. Критерий похожести (merge vs new pattern)

- **distance_shape** = |log(xy_new/xy_ref)| + |log(xz_new/xz_ref)|. Порог **T_shape** (дефолт ~0.25–0.4).
- **distance_glyph** = mean(|glyph_new[i] − glyph_ref[i]|) при нормализации 0..1. Порог **T_glyph** (дефолт ~0.15–0.25).
- **Merge** по MergeOrAddByShape: форма (CoarseSig/near_sig/fallback) или при пустой форме — по GlyphData + freq + ratio. Иначе — **новый** Pattern.

## 4. Дефолтные параметры

- **W**: 0.6 с (окно для глифа и стационарности).
- **dt**: 100 ms (шаг детекции).
- **T_lock**: 0.5 с (hold стационарности для LOCK).
- **A_cv**: 0.15 (std(env)/mean(env) < A_cv).
- **A_slope**: 0.25 (|slope(env)|/mean(env) < A_slope, 1/с).
- **Δf_merge**: 1 бин (строже Δf_lock, который 1/3/5 бинов).
- **T_shape**: 0.35; **T_glyph**: 0.20.
- **min_freq**: 20 Гц.

## 5. Replace glyph (опционально)

- Кнопка/действие «Replace glyph» по выбранному токену: взять текущий x/fs, f0 паттерна, вызвать `ComputeFrozenGlyphFromWindow(x, fs, f0, W)` (или ComputeFrozenGlyph), затем `PatternStore.ReplaceGlyphByID(id, glyph)`. Только по явному действию пользователя.
